# pygame-rs 三端构建与运行指南

> pygame-rs 是 starfish 游戏引擎的 **Python 绑定层**（独立 crate）：
> 内嵌 RustPython 解释器 + 原生 `pygame` 模块（`#[pymodule]` 树）。
> 三平台：**Windows 桌面 / Web（wasm32）/ Android（arm64 真机，鸿蒙
> NEXT + 卓易通容器实测）**。
>
> 本文是 pygame-rs 的**一站式构建/运行入口**；专项细节见同目录
> `wasm编译与运行指南.md`、`android构建与运行指南.md`、
> `安卓APK打包lib_name坑与真机诊断手册.md`。

---

## 一、前置准备（每台机器一次性）

```bash
# Rust 目标（三端）
rustup target add wasm32-unknown-unknown
rustup target add aarch64-linux-android

# wasm 胶水工具（版本必须与 Cargo.lock 严格一致，当前 0.2.127——
# 不一致报 "not compatible with version of the wasm-bindgen ..."）
cargo install wasm-bindgen-cli --version 0.2.127

# Android 打包工具
cargo install cargo-ndk
```

环境变量（Android 未设时脚本按常见路径探测，如 `D:/SDK/Android`）：
- `ANDROID_HOME`：Android SDK 路径
- `ANDROID_NDK_ROOT`：NDK 路径
- `ANDROID_JAR`：robius/dialog 需要（`...\platforms\android-37.0\android.jar`）

## 二、桌面（Windows）

```bash
cargo run --release -p pygame-rs --example <示例名>
```

示例（`--release` 为验收口径；debug 已可用，但性能验收以 release 为准）：

| 示例 | 说明 |
|---|---|
| `sig_probe` | 签名契约锚点（**无头零窗口**，先于真机跑；130+ 项断言，终端看 `[OK]`/`FAIL`） |
| `binding_probe` | M1 绑定面验收（标准 pygame 写法：with 会话渲染 + font + mixer + 手柄/触摸查询） |
| `font_test` | pygame.font 专项（构造/度量/旋转缩放/半透明/CJK 链路，`[font-test]` 行） |
| `draw_test` | pygame.draw 专项（六形状 + 半透明 + gfxdraw 兼容混绘，`[draw-test]` 行） |
| `transparent_test` | 透明窗口专项（桌宠形态：`TRANSPARENT | DIRECTX` 逐像素透明，`[transparent-test]` 行） |
| `rp_hello` | M0 嵌入冒烟（RP 创世纪 / 语言特性 / 冻结 stdlib） |

> 观察 Python `print` 输出、且重定向到文件时，加 `PYTHONUNBUFFERED=1`
> （stdout 块缓冲，强杀进程会丢未刷行）；窗口类示例用
> `timeout 20 cargo run ...` 截停法验证持续运行（exit 124 = 正常）。

## 三、Web（wasm32）

```bash
# 构建（wasm32 + 胶水 + HTML 加载页，产物落本仓库 web/）
python scripts/build_web.py <示例名>

# 本地服务（file:// 无效，必须 http 服务）
cd web && python -m http.server 8000
# 浏览器打开 http://localhost:8000/<示例名>.html
```

- 窗口类示例（binding_probe/font_test/draw_test/transparent_test）为 canvas 页；
  `sig_probe`/`rp_hello` 为控制台页（结果在 **F12**）。
- `--all` 全量构建；REGISTRY 在 `scripts/build_web.py` 顶部（新增示例须登记）。
- 页面带【pygame-rs】归属标识；产物只进 `pygame-rs/web/`（与 starfish 侧不混放）。
- 已知边界：Web 无文件系统（`Font(路径)`/`pygame.io` 同步面报错或 SKIP，
  资源走宿主预加载/`load_from_bytes`）；音频须首次手势解锁
  （`pygame.mixer.needs_gesture()`）。

## 四、Android（arm64 APK）

```bash
# 统一打包链（唯一入口；xtask 已退役）
python scripts/build_apk.py <示例名>          # pygame-rs 示例
python scripts/build_apk.py hello --dir ..    # starfish 根 crate 示例共用本脚本
```

产物：`target/android-apk/<名>_android.apk`。链路：cargo ndk（RP 恒
release）→ llvm-strip → aapt2 重造 base（lib_name 对齐示例名）→ 组装
（.so 恒 ZIP_DEFLATED）→ zipalign → apksigner。

```bash
# 安装运行（模拟器冒烟必须 x86_64 原生包：--abi x86_64，arm64 走翻译层不可信）
adb install -r target/android-apk/<名>_android.apk
adb logcat | grep -E "selftest|diag"     # 或卓易通不可信时看 /sdcard/Download/bp_log.txt
```

**关键坑速查**（详见 CLAUDE.md「Android 实机关键坑」）：
- 秒退先查 lib_name：`aapt2 dump xmltree --file AndroidManifest.xml <apk> | grep -A2 lib_name`，value 必须 = `<名>_android`
- GL 纹理 ID 复用串内容：transform 源表面必须保活（ADR-5 红线延伸）
- 启动后立即 set_mode + set_mode 后立即 fill+flip 铺底（防白闪）

## 五、双注册惯例（新增示例）

一个源文件注册两条 `[[example]]`（`Cargo.toml`）：

```toml
[[example]]
name = "my_test"

[[example]]
name = "my_test_android"
path = "examples/my_test.rs"
crate-type = ["cdylib"]        # cargo-ndk 4.x 不自动转换
```

Web 侧再往 `scripts/build_web.py` 的 REGISTRY 加一行
（`"my_test": (True, "描述")`，`True`=窗口类 canvas 页）。

## 六、逐模块独立测试（当前进行中）

共享宿主壳 `rpy::testhost::run(script, tag, transparent)` 固化装配/字体
预载/事件泵/帧循环/收口——模块案例只写 Python 脚本（`examples/<模块>_test.py`），
`.rs` 三行壳 + 脚本内 `[模块-test] PASS/FAIL` 逐项断言 + 样张上屏。

已完成：`font_test`（font）、`draw_test`（draw + gfxdraw）、
`transparent_test`（透明窗口）。`binding_probe` / `sig_probe` 保留不动。

3. 目标模块 `_test`（专项）
