## 一、核心说明

这套着色器支持你现在的扁平顶点格式：

- 支持三种拓扑：三角形、线框、点

## 二、万能 WGSL 着色器代码

```wgsl
// 顶点输入：位置 + 颜色（和你现在的 Rust 布局完全对应）
struct VertexInput {
    @location(0) position: vec3<f32>,
    @location(1) color: vec3<f32>,
}

// 顶点输出：传递插值颜色到片段着色器
struct VertexOutput {
    @builtin(position) clip_pos: vec4<f32>,
    @location(0) out_color: vec3<f32>,
}

// 可选：如果你后面要加 MVP 矩阵，直接用这个 uniform 块
// struct MVP {
//     model: mat4x4<f32>,
//     view: mat4x4<f32>,
//     proj: mat4x4<f32>,
// }
// @group(0) @binding(0) var<uniform> mvp: MVP;

@vertex
fn vs_main(in: VertexInput) -> VertexOutput {
    var out: VertexOutput;

    // 方案1：直接传递位置（适配你当前无投影的场景，坐标在 NDC 空间）
    out.clip_pos = vec4<f32>(in.position, 1.0);

    // 方案2：如果后面要加 MVP 变换，替换上面一行即可
    // out.clip_pos = mvp.proj * mvp.view * mvp.model * vec4<f32>(in.position, 1.0);

    // 传递颜色，自动插值
    out.out_color = in.color;
    return out;
}

@fragment
fn fs_main(in: VertexOutput) -> @location(0) vec4<f32> {
    // 直接输出插值后的颜色，alpha=1.0
    return vec4<f32>(in.out_color, 1.0);
}
```

## 三、怎么用它渲染三角形 / 线框 / 点？

着色器不用改，只要在创建 `RenderPipeline` 时修改**拓扑类型**：

### 1\. 渲染实心三角形（你现在的用法）

```rust
let primitive = wgpu::PrimitiveState {
    topology: wgpu::PrimitiveTopology::TriangleList,
    ..Default::default()
};
```

### 2\. 渲染线框（三角形的边）

```rust
let primitive = wgpu::PrimitiveState {
    topology: wgpu::PrimitiveTopology::TriangleList,
    polygon_mode: wgpu::PolygonMode::Line, // 线框模式
    ..Default::default()
};
```

### 3\. 渲染线段（两点一条线）

```rust
let primitive = wgpu::PrimitiveState {
    topology: wgpu::PrimitiveTopology::LineList,
    ..Default::default()
};
```

### 4\. 渲染点（每个顶点一个点）

```rust
let primitive = wgpu::PrimitiveState {
    topology: wgpu::PrimitiveTopology::PointList,
    ..Default::default()
};
```

## 四、补充说明

1. 这套着色器和你现在的 Rust 顶点数据完全兼容，不用改任何代码，直接替换 `triangle.wgsl` 即可。

2. 后面你要做 3D 投影，只需要取消 `MVP` 矩阵的注释，在 Rust 里传一个 uniform 缓冲区就行，着色器不用动。

3. 如果你想加纹理，只需要在 `VertexInput` 里加一个 `uv: vec2<f32>` 字段，片段着色器里采样纹理，其他逻辑不变。
